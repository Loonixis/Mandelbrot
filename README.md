# Mandelbrot Explorer

A small interactive Mandelbrot set explorer written in C using [raylib](https://www.raylib.com/). Zoom in at the cursor, pan around the fractal, and adjust the iteration limit.

## Features

- Zoom toward the mouse cursor with the scroll wheel
- Pan by dragging with the left mouse button
- Move with the arrow keys or WASD
- Increase or decrease the iteration limit
- Save a screenshot as `mandelbrot.png`
- Reset the view

## Requirements

- Windows
- C compiler
- raylib for Windows
